# 暴雨公式表格维护

暴雨公式由 CSV 表格读取。Excel、WPS 和 LibreOffice 均可编辑；保存时选择 **CSV UTF-8（逗号分隔）**，不要直接上传 `.xlsx`、`.xls` 或把它们改后缀。程序也能读取 GBK / GB18030 编码的 CSV。

## 使用步骤

1. 打开“降雨序列”，把序列来源设为“暴雨公式 · 芝加哥雨型”。
2. 首次了解格式时点“下载表格样板”；若要在现有公式上新增，点“下载完整公式表”。
3. 用 Excel / WPS 打开，复制同类型公式行，改成新城市、分区、系数、适用范围及来源。**保留第一行的24个中文列名**，可以调整列的顺序。
4. 另存为 CSV UTF-8，点“导入 CSV”。导入成功后，选择城市 / 分区，填写设计重现期、历时、雨峰系数和采样步长，再生成降雨序列。
5. 该次导入会替换当前公式列表；需要保留原有城市时，请在完整公式表上追加行。格式有误则整张表拒绝导入，原公式列表保留。导入和运算在本地 Worker 内完成，可取消，不上传文件。

导入仅在当前页面会话有效，刷新页面后恢复内置表格。“恢复内置表格”可以立即恢复。请把自己维护的 CSV 留在本机，下次重新导入。

如果希望更新网站的默认公式列表，直接编辑项目中的 [src/data/rainfall-formulas.csv](../src/data/rainfall-formulas.csv)，运行 `npm run check` 和 `npm run test:browser` 后重新构建、部署。无需修改 TypeScript。样板文件是 [src/data/rainfall-formulas-template.csv](../src/data/rainfall-formulas-template.csv)。样板中的系数来自现有南京和深圳条目，替换为新城市时须一并更新来源，不能沿用示例来源。

## 两种填写方式

| 公式类型 | 计算形式 | 每个公式ID占几行 | 重现期怎么填 |
| --- | --- | --- | --- |
| 含P公式 | `A × (1 + C × lg P) / (t + b)^n` | 一行 | 填P最小值、P最大值；P固定值留空 |
| 固定P公式 | `A / (t + b)^n` | 每个P一行，同一分区重复相同ID | 填P固定值；P最小值、P最大值、C留空 |

`lg` 为以10为底的对数。`t`、`b` 为分钟，`P` 为年。不能在单元格里写 `=...`、`log(P)` 或任意表达式；应填最终数值，保存为CSV后检查内容。若 `A`、`b` 或 `n` 随P改变，可按官方公布的每一个P分别计算并填“固定P公式”行；工具只允许表里列出的P，不插值。

例如原式为 `(a + c × lg P)/(t+b)^n`，需先换算成 `A=a`、`C=c/a`，并核对单位和精度。分段历时、其他对数形式或其他表达式不能直接填入当前两种模板。

## 列填写说明

| 列名 | 必填 / 规则 |
| --- | --- |
| 公式ID | 必填，唯一标识，如 `haikou-main-2026`。用字母、数字、点、短横线、下划线，以字母或数字开头；`manual`保留不可用。不同地区、版本、历时段使用不同ID。 |
| 城市 | 必填，如“南京”。 |
| 分区名称 | 必填，如“江南区域”。 |
| 适用地域 | 必填，写清适用行政区域或流域，避免扩大地域。 |
| 公式类型 | 必填，只选“含P公式”或“固定P公式”。 |
| 雨强单位 | 必填，只选 `mm/h`、`mm/min`、`L/(s·ha)`。单位切换不自动换算系数。 |
| A | 必填，有限正数。固定P行填写该P对应的分子系数。 |
| C | 含P公式必填，有限数值且≥0；没有该项可填0。固定P行留空。 |
| b | 必填，有限正数，单位min。 |
| n | 必填，有限正数；允许大于1。生成芝加哥雨型时仍检查 `T ≤ b/(n−1)`。 |
| P最小值_年 | 含P公式必填，>0；固定P行留空。 |
| P最大值_年 | 含P公式必填，≥P最小值；固定P行留空。 |
| P固定值_年 | 固定P公式必填，>0。同一ID下不能重复；含P公式留空。 |
| 历时最小值_min | 与最大值同时填，>0；都留空表示原文有效历时未明确，不是无限适用。 |
| 历时最大值_min | ≥最小值。填写官方范围；若额外采用工具限制，要在备注中明确。 |
| 雨峰系数r | 可留空；填时须满足0<r<1，为资料中的建议值。最终按页面填写的r生成，需自行确认。 |
| 来源标题 | 必填，官方通知、标准或报告的名称。 |
| 来源链接 | 必填，`https://`链接。请填写能核实系数的官方原文入口。工具不自动访问或验证链接的权威性。 |
| 附件链接 | 可留空；填写时须为`https://`链接。 |
| 版本 | 必填，文号、标准号或版本日期。 |
| 发布日期 | 必填文本，如`2026-01-01`、`2026`或“2024（2025公开）”。 |
| 核实日期 | 必填，`YYYY-MM-DD`格式，如`2026-10-27`。表示维护者核对日期，不自动证明当前版本最新。 |
| 原文位置 | 必填，页码、表号、章节或式号，便于复核。 |
| 备注 | 可留空；记录未知项、工具额外限制及适用性说明。 |

固定P公式的同一ID各行中，城市、分区、地域、单位、历时范围、雨峰系数、来源、版本、备注必须一致；只允许P、A、b、n不同。

## 校验与报告

最大2MB、5000条数据行。重复/缺失/未知列、缺参、非有限数值、重复重现期、同一ID元数据不一致等都会报错，并指出数据行。引号、逗号、换行按标准CSV处理；不要用中文逗号替换列分隔符，也不要添加说明行或合并单元格。

导入表格中的文字只作为文字显示，系数不作为脚本或表格公式执行。导入条目在页面和下载报告中标为“用户导入”，报告保存表格文件名、来源字段和实际使用的系数；不会把填写的“核实日期”当作工具已核实的证明。生成的芝加哥雨型仍不等同于地方官方指定设计雨型，见[雨型算法与限制](rainfall.md)。
