# 暴雨公式表格维护

默认目录为 [src/data/rainfall-formulas.csv](../src/data/rainfall-formulas.csv)，已整合所提供的全国城市汇总表。页面通过搜索、城市筛选和分区/版本选择公式，不提供公式表下载、导入或恢复入口。

## 维护步骤

1. 用 Excel、WPS 或 LibreOffice 打开仓库中的 CSV。也可参考 [维护样板](../src/data/rainfall-formulas-template.csv)，复制同类型公式行。
2. 修改城市、分区、系数、适用范围和来源，保留24个基础中文列名及目录中的可选规则列；可以调整列顺序。
3. 保存为 **CSV UTF-8（逗号分隔）**。不要保存成 xlsx 后直接改后缀。
4. 运行 `npm run check` 与 `npm run test:browser`，提交并推送仓库。GitHub Pages 工作流构建后更新页面默认目录，无需修改 TypeScript。

## 两种填写方式

| 公式类型 | 计算形式 | 每个公式ID占几行 | 重现期怎么填 |
| --- | --- | --- | --- |
| 含P公式 | `A × (1 + C × lg P) / (t + b)^n` | 一行 | 填P最小值、P最大值；P固定值留空 |
| 固定P公式 | `A / (t + b)^n` | 每个P一行，同一分区重复相同ID | 填P固定值；P最小值、P最大值、C留空 |

`lg` 为以10为底的对数。`t`、`b` 为分钟，`P` 为年。不能在单元格里写 `=...`、`log(P)` 或任意表达式；应填最终数值，保存为CSV后检查内容。若 `A`、`b` 或 `n` 随P改变，可按官方公布的每一个P分别计算并填“固定P公式”行；工具只允许表里列出的P，不插值。

例如原式为 `(a + c × lg P)/(t+b)^n`，需先换算成 `A=a`、`C=c/a`，并核对单位和精度。不同历时段应使用独立ID与明确边界，不会自动拼接为地方分段设计雨型。除下述内置特殊规则外，其他表达式不能直接填入当前两种模板。

## 列填写说明

| 列名 | 必填 / 规则 |
| --- | --- |
| 公式ID | 必填，唯一标识，如 `haikou-main-2026`。用字母、数字、点、短横线、下划线，以字母或数字开头；`manual`保留不可用。不同地区、版本、历时段使用不同ID。 |
| 城市 | 必填，如“南京”。 |
| 分区名称 | 必填，如“江南区域”。 |
| 适用地域 | 必填，写清适用行政区域或流域，避免扩大地域。 |
| 公式类型 | 必填，只选“含P公式”或“固定P公式”。 |
| 雨强单位 | 必填，只选 `mm/h`、`mm/min`、`L/(s·ha)`（也接受等价的`L/(s·hm²)`和`L/(s·hm2)`）。单位切换不自动换算系数。 |
| A | 必填，有限正数。固定P行填写该P对应的分子系数。 |
| C | 含P公式必填，有限数值且≥0；没有该项可填0。固定P行留空。 |
| b | 必填，有限正数，单位min。 |
| n | 必填，有限正数；允许大于1。生成芝加哥雨型时仍检查 `T ≤ b/(n−1)`。 |
| P最小值_年 | 含P公式填写时>0，可与最大值同时留空表示范围未明确；固定P行留空。 |
| P最大值_年 | 含P公式填写时≥P最小值，可与最小值同时留空；固定P行留空。 |
| P固定值_年 | 固定P公式必填，>0。同一ID下不能重复；含P公式留空。 |
| 历时最小值_min | 填写时>0；允许单侧或两侧留空，表示对应范围未明确，不是无限适用。 |
| 历时最大值_min | ≥最小值。填写官方范围；若额外采用工具限制，要在备注中明确。 |
| 雨峰系数r | 可留空；填时须满足0<r<1，为资料中的建议值。最终按页面填写的r生成，需自行确认。 |
| 来源标题 | 必填，官方通知、标准或报告的名称。 |
| 来源链接 | 必填，`http://`或`https://`链接。请填写能核实系数的官方原文入口。工具不自动访问或验证链接的权威性。 |
| 附件链接 | 可留空；填写时须为`http://`或`https://`链接。 |
| 版本 | 必填，文号、标准号或版本日期。 |
| 发布日期 | 必填文本，如`2026-01-01`、`2026`或“2024（2025公开）”。 |
| 核实日期 | 必填，`YYYY-MM-DD`格式，如`2026-10-27`。表示维护者核对日期，不自动证明当前版本最新。 |
| 原文位置 | 必填，页码、表号、章节或式号，便于复核。 |
| 备注 | 可留空；记录未知项、工具额外限制及适用性说明。 |

固定P公式的同一ID各行中，城市、分区、地域、单位、历时范围、雨峰系数、来源、版本、备注及规则列必须一致；只允许P、A、b、n不同。

## 可选规则列

| 列名 | 规则 |
| --- | --- |
| 计算规则 | 留空为标准模板；可填`海口总公式I`、`海口总公式II`或`b乘P的0.031次方`，仅用于含P公式。不能填任意表达式。 |
| P下限开区间 | 填`是`表示P严格大于已填下限，否则含下限。 |
| 历时下限开区间 | 填`是`表示t严格大于已填下限，否则含下限。 |
| 历时上限开区间 | 填`是`表示t严格小于已填上限，否则含上限。 |

海口两式均以`PE=1/[-ln(1-1/P)]`代替公式中的P。总公式I限短历时、P≤10；总公式II在t≤180min时要求P>10，t>180min时采用条目P范围。贵阳规则以`b列×P^0.031`作为实际b。设计重现期仍按原P记录。

## 校验与报告

最大2MB、5000条数据行。重复/缺失/未知列、缺参、非有限数值、重复重现期、同一ID元数据不一致等都会报错，并指出数据行。引号、逗号、换行按标准CSV处理；不要用中文逗号替换列分隔符，也不要添加说明行或合并单元格。

表格文字只作为文字显示，系数不作为脚本或表格表达式执行。来源链接与核实日期按表格记录，不自动证明版本现行或权威性。当前条目的原文位置、适用范围、备注、特殊规则及实际参数进入下载报告。生成的芝加哥雨型不等同于地方官方指定设计雨型，见[雨型算法与限制](rainfall.md)。
