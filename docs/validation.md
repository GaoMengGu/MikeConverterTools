# 浏览器转换与 Pages 验收

本项目采用 GitHub Pages 托管静态页面，输入文件由浏览器 Web Worker 处理。
测试仅使用合成数据，不上传真实工程图纸或测点。

## 自动验证

推送 `main` 后，GitHub Actions 执行以下检查，通过后发布 `dist`：

1. 安装锁定版本的网页构建与测试依赖。
2. 执行 45 项转换核心测试、TypeScript 检查和生产构建。
3. 使用构建环境预装的 Chrome 测试生产页面，桌面与手机各 14 项，共 28 项。
4. 将静态构建产物部署到 GitHub Pages。

浏览器检查覆盖边界五列输出、实际下载、低值过滤、分带错误、分区优先级、
未覆盖点默认赋值、开口线拒绝、报告参数、输入变更清除结果、超限文件拒绝、
取消后恢复及 GBK 中文图层。截图和 Canvas 像素检查用于核对预览及手机布局。
降雨检查涵盖雨强单位、日期、时间顺序、缺值拒绝、数据值类型和总雨量积分；
芝加哥雨型检查涵盖模板缺参、公式单位、雨峰系数及不同步长下的理论雨量守恒。

## 工程核验

自动检查覆盖浏览器转换与文本输出，尚不包含 MIKE 2024 内的实际导入试验。
项目使用时应在 MIKE 中核对闭合边界、点数、坐标范围与高程。
分区赋值结果第三列为参数值，分带前缀处理不执行坐标重投影。
