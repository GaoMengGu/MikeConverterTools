# 暴雨强度公式目录

默认目录为 [src/data/rainfall-formulas.csv](../src/data/rainfall-formulas.csv)，已整合用户提供的全国城市汇总表：133行系数，合并为34个城市、70个分区/版本条目。同一ID的固定重现期系数合并为一个条目，按P查表，不插值。

在“降雨序列 → 暴雨公式 · 芝加哥雨型”中搜索城市、分区或版本，再按城市筛选、选择分区/版本。选择项标注P和历时边界，帮助区分同名分区的不同公式。页面只展示当前条目的来源、版本、适用地域、范围、原文位置、备注及链接；不展示全局核实进度或未启用城市。

默认保留手动输入模式。选定目录公式后，系数、形式、单位和来源锁定，P、历时、步长和雨峰系数由用户填写。对于随P变化的系数，页面注明预览使用的P，生成时Worker依据实际P重新解析。切回手动后可编辑系数，并清除目录来源标记。

目录保留汇总表给出的系数、来源链接与版本说明。**汇总表包含官方发布、规划公示、征求意见稿、论文及转载材料，整合并不等于逐条重新核实其为最新现行官方版本。**请核对当前条目的备注与项目所在地要求；未知范围显示为未明确，表中工具限制也保留在备注中。网页不会自动抓取或验证来源链接。

海口重现期修正、贵阳随P变化的b以及严格P/t边界由目录规则列表达，详见[表格维护说明](formula-table.md)。`n>1`本身不会被拒绝；连续芝加哥生成仍要求`T≤b/(n−1)`。来源、范围、特殊规则和实际系数随下载报告保存。

本工具对选定IDF公式生成连续芝加哥雨型，保持总雨量；不会自动拼接不同条目的历时分段，也不会生成地方时程分配表。所选公式的有效历时与峰附近的数学延拓不同，工程使用须结合当地规定雨型，见[算法与限制](rainfall.md)。
