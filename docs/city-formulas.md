# 官方暴雨强度公式目录

在“降雨序列 → 暴雨公式 · 芝加哥雨型 → 城市 / 分区公式”选择条目。默认仍是手动输入。选定条目后系数、公式形式、单位和来源锁定；重现期、总历时、采样步长和雨峰系数由用户设置。切回手动可编辑，但会清除官方来源标记。

首批核实日期为2026-10-23，共5城16个分区条目。这里只承诺核对所列官方版本原文，不能保证实时最新或全国覆盖。来源、附件位置、地域、范围、已知未知项随条目显示并进入下载报告。除官方公布的范围之外，不把工具限制伪称为原文规定。

数据模块为 src/core/city-formulas.ts。参数结构固定，不执行网页抓取或任意表达式。深圳、广州按原文单一P公式查系数，不插值、不用一条总公式代替分区表。两地1年公式及区间参数表达式暂未开放，其中存在n>1形式，不能硬套当前芝加哥积分模板。

南京江南：i=16.696(1+0.954lgP)/(t+18.825)^0.751，江北：i=18.896(1+0.628lgP)/(t+16.802)^0.756，单位mm/min。原文另外给出的q系数经过独立四舍五入，工具不混用两个量纲的系数。

本工具依据选定IDF公式生成连续芝加哥雨型的时段积分，保持总雨量；**这不等同于地方官方指定设计雨型**。各地可能提供时程分配表或其他雨型，工程使用需按当地要求。公式的短历时有效范围与连续芝加哥雨峰附近的数学延拓是不同概念，当前模板对峰附近继续使用所选函数，不表明该极短历时得到地方资料验证。雨峰系数没有官方核实值时保持由用户填写。

北京已定位[DB11/T969-2016官方全文](https://ghzrzyw.beijing.gov.cn/biaozhunguanli/bz/cxgh/202002/t20200220_1662906.html)，其分区及分历时公式需要分段雨型处理，尚不启用。上海、武汉、昆山、郑州显示官方资料入口和未核实原因。成都、西安、杭州、海口、三亚尚未完成当前官方原文核对，未填参数，不使用第三方转载的旧公式冒充。未收录不表示当地没有公式。
