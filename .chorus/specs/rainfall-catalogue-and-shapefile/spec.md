## Intent
在静态 Pages 应用中提供可追溯的地方暴雨公式，并让普通 CAD 地物可在浏览器内转为 GIS 数据。

## Requirements
- [x] 城市/分区条目保存官方链接、发布日期/版本、核实日期、系数、单位、适用范围及未知项。
- [x] 支持的公式可选入芝加哥生成器；校验重现期/历时，报告保存来源和实际参数。
- [x] 默认手填公式仍可用；未知参数和不适配的公式不伪装成可用城市预设。
- [x] DXF 点、直线、普通多段线导出点线面 SHP/SHX/DBF/CPG ZIP。
- [x] 记录未转换对象和二维降维；保持坐标，不自动推断 CRS，不填默认 WGS84。
- [x] Worker 可终止取消；中文属性、SHP 独立读回、桌面/移动端实际下载验收。

## Non-goals
- 全中国城市一次性全覆盖或自动跟踪政策更新。
- 重投影、CAD 符号样式复刻、块递归变换、曲线自动离散、嵌套孔洞推断。
- 上传用户文件或收集外部分析数据。
