# 官方暴雨公式库与 DXF 转 SHP

本次先收录全国主要城市中可核实的官方原文，不以第三方汇总替代来源。深圳新版分流域并废止2015版 [1](ref:2116e579-15f6-4eca-928f-514fa19b5d88)；北京标准分区和分历时 [2](ref:1037b14f-edb6-47fc-8337-9a892412cac6)；天津标准按四区计算 [3](ref:8dbd8a2b-2df7-4336-b7c0-e8eeae1d6133)。预设显示版本、适用地域、单位、P/t范围、核实日期和官方链接。默认手填；选定预设后锁定官方系数，变更地域和P重新解析，报告保留来源。生成器仍使用积分守恒的芝加哥雨型，不声称代替地方规定雨型。

DXF 导出使用既有 dxf-parser 和成熟 Shapefile 写入库。点、文字定位点（TEXT/MTEXT原文属性）、直线、普通多段线按几何分组为 points/lines/polygons；闭合多段线默认作为闭合线，用户可选择独立简单面。面执行自交检查、闭合与方向规范，不推断孔洞。导出二维几何，Z范围保留属性，明确逐点Z不会保留。块、圆等复杂实体及布局空间对象按类型统计；圆弧多段线、网格、非默认OCS对象报错停止，零可导出时报错。原始ENTITIES组码清单用于发现解析器不支持且会跳过的实体。

默认原坐标原样写入且无PRJ；仅当源坐标已确认CGCS2000分带时，可显式选择补带号并生成对应PRJ；此操作不重投影。不得根据附近数值、带号或已有坐标栏伪造CRS。用户可选择提供源PRJ WKT而保持坐标原样，不可与补带号同时使用。ZIP包含SHP/SHX/DBF/CPG、转换报告及说明。中文属性必须独立读回验证。对过长字段报错而不静默截断。

验收：行为测试先失败再实现；公式数值/范围/版本测试；独立SHP与DBF读回；npm run check；npm run test:browser；桌面/移动端布局和实际下载；输入变更使旧结果失效，运行时可终止Worker取消。项目规则中原有MIKE坐标、过滤、赋值行为保持测试通过。不推送或部署。

首批启用5城16个分区条目：南京2、天津4、深圳4、广州5、常州1（短历时）。深圳和广州按8个指定重现期单独表取系数，不插值；n>1的1年公式暂不开放。北京/上海/武汉/昆山/郑州及其他城市显示核实进度而不填未核实系数。天津历时边界未知且本工具限制P2–100年；常州下限与P范围为工具限制，界面明确其非原文拟合边界。所有条目保留官方版本核实日期，不声称实时最新。
